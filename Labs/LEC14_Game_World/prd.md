# LEC14 게임 월드 - 공 발사 방향 메시지 PRD

## 1. 문서 개요

### 1.1 목적

소년이 스페이스 키를 입력했을 때 현재 바라보는 방향으로 공을 실제 발사하고, 발사 방향을 콘솔에 메시지로 출력한다.

### 1.2 대상

- `Labs/LEC14_Game_World/main.py`
- `Labs/LEC14_Game_World/boy.py`
- `Labs/LEC14_Game_World/game_world.py`

## 2. 기능 목표

1. 소년의 좌우 이동 방향을 현재 바라보는 방향으로 저장한다.
2. 스페이스 키 입력을 감지한다.
3. 스페이스 키 입력 시 저장된 바라보는 방향을 발사 방향으로 사용한다.
4. 발사 방향을 다음 형식의 메시지로 출력한다.

```text
볼 발사 방향: 왼쪽
볼 발사 방향: 오른쪽
```

5. 발사 이벤트마다 공 객체를 생성해 게임 월드에 등록한다.
6. 공은 발사 방향으로 이동하고 화면 밖으로 나가면 게임 월드에서 제거한다.

## 3. 사용자 시나리오

### 시나리오 A: 오른쪽을 바라보며 발사

1. 사용자가 게임을 실행한다.
2. 오른쪽 방향키를 누른다.
3. 소년이 오른쪽으로 이동하고 오른쪽을 바라본다.
4. 사용자가 스페이스 키를 누른다.
5. 콘솔에 `볼 발사 방향: 오른쪽`이 출력된다.
6. 화면에 공이 나타나고 오른쪽으로 이동한다.

### 시나리오 B: 왼쪽을 바라보며 발사

1. 사용자가 왼쪽 방향키를 누른다.
2. 소년이 왼쪽으로 이동하고 왼쪽을 바라본다.
3. 사용자가 스페이스 키를 누른다.
4. 콘솔에 `볼 발사 방향: 왼쪽`이 출력된다.
5. 화면에 공이 나타나고 왼쪽으로 이동한다.

### 시나리오 C: 이동하지 않고 발사

1. 게임 시작 상태에서 소년은 기본 방향인 오른쪽을 바라본다.
2. 사용자가 스페이스 키를 누른다.
3. 콘솔에 `볼 발사 방향: 오른쪽`이 출력된다.

### 시나리오 D: 수면 상태에서 발사

1. 소년이 일정 시간 동안 움직이지 않아 수면 상태가 된다.
2. 사용자가 스페이스 키를 누른다.
3. 소년은 깨어난다.
4. 현재 바라보는 방향에 대한 발사 메시지가 출력된다.

## 4. 상세 요구사항

### 4.1 방향 상태

- `Boy.face_dir`를 현재 바라보는 방향으로 사용한다.
- `face_dir` 값은 다음과 같이 정의한다.
  - `1`: 오른쪽
  - `-1`: 왼쪽
- 오른쪽 또는 왼쪽 방향키 입력 시 `face_dir`를 갱신한다.
- 이동을 멈춰도 마지막으로 바라본 방향은 유지한다.
- 초기 방향은 오른쪽으로 설정한다.

### 4.2 스페이스 키 처리

- `SDL_KEYDOWN` 이벤트의 `SDLK_SPACE`를 발사 입력으로 처리한다.
- `Boy.handle_event()`는 스페이스 입력 시 `face_dir`를 반환한다.
- 수면 상태에서는 먼저 소년을 깨운 뒤 `face_dir`를 반환한다.
- `main.py`는 반환된 방향을 한글 메시지로 변환해 출력한다.

### 4.3 출력 메시지

- 오른쪽 방향일 때:

```text
볼 발사 방향: 오른쪽
```

- 왼쪽 방향일 때:

```text
볼 발사 방향: 왼쪽
```

- 방향키가 아닌 이벤트나 스페이스가 아닌 키 입력에는 발사 메시지를 출력하지 않는다.
- 출력은 게임 화면이 아닌 실행 콘솔에 표시한다.

### 4.4 공 동작

- 공은 `ball21x21.png` 이미지를 사용한다.
- 공의 시작 위치는 소년의 현재 위치에서 바라보는 방향으로 일정 거리 떨어진 지점이다.
- 공은 매 프레임 바라보는 방향으로 이동한다.
- 공이 캔버스의 좌우 경계를 벗어나면 게임 월드에서 제거한다.
- 공은 게임 월드에서 소년보다 앞선 깊이로 렌더링한다.

### 4.5 제외 범위

다음 기능은 이번 요구사항에 포함하지 않는다.

- 공과 캐릭터 또는 지형의 충돌 처리
- 발사 방향을 화면 내부에 텍스트로 그리는 기능
- 발사 횟수, 점수, 사운드, 파티클 효과

## 5. 구현 계획

### 단계 1: 소년 방향 상태 확인

- `Boy`에 `face_dir` 상태를 둔다.
- 좌우 입력 처리에서 이동 방향과 바라보는 방향을 함께 갱신한다.
- 이동 종료 후에도 `face_dir`가 유지되는지 확인한다.

### 단계 2: 발사 입력 반환

- `Boy.handle_event()`에서 스페이스 키를 처리한다.
- 일반 상태에서는 현재 `face_dir`를 반환한다.
- 수면 상태에서는 `wake_up()`을 호출한 후 현재 `face_dir`를 반환한다.

### 단계 3: 메시지 출력 연결

- `main.py`에서 `boy.handle_event()`의 반환값을 받는다.
- 반환값이 있을 때만 방향을 한글 문자열로 변환한다.
- 방향 메시지를 콘솔에 출력한다.

### 단계 4: 공 생성 및 이동 구현

- 스페이스 입력 시 소년의 위치와 방향을 기준으로 `Ball` 객체를 생성한다.
- 생성한 공을 게임 월드에 등록한다.
- 매 프레임 공을 이동시키고 화면 밖에서 제거한다.

## 6. 완료 조건

- [ ] 오른쪽을 바라볼 때 스페이스 입력으로 `볼 발사 방향: 오른쪽`이 출력된다.
- [ ] 왼쪽을 바라볼 때 스페이스 입력으로 `볼 발사 방향: 왼쪽`이 출력된다.
- [ ] 이동을 멈춘 뒤에도 마지막 방향으로 메시지가 출력된다.
- [ ] 초기 상태에서 스페이스 입력 시 오른쪽 메시지가 출력된다.
- [ ] 수면 상태에서 스페이스 입력 시 깨어나고 방향 메시지가 출력된다.
- [ ] 스페이스 입력으로 공 오브젝트가 생성된다.
- [ ] 공이 소년의 현재 방향으로 이동한다.
- [ ] 화면 밖으로 나간 공이 게임 월드에서 제거된다.
- [ ] 방향키와 스페이스 외의 입력으로 발사 메시지가 출력되지 않는다.
- [ ] 기존 소년 이동 및 애니메이션 동작이 유지된다.

## 7. 검증 방법

### 정적 검증

```powershell
python -m py_compile main.py boy.py game_world.py
```

### 수동 검증

1. `Labs\LEC14_Game_World`에서 `python main.py`를 실행한다.
2. 오른쪽 방향키 후 스페이스를 눌러 오른쪽 메시지를 확인한다.
3. 왼쪽 방향키 후 스페이스를 눌러 왼쪽 메시지를 확인한다.
4. 방향키를 놓은 뒤 스페이스를 눌러 마지막 방향이 유지되는지 확인한다.
5. 화면에 공이 나타나고 소년의 방향으로 이동하는지 확인한다.
6. 공이 화면 밖으로 나간 뒤 정상적으로 제거되는지 확인한다.
7. `ESC` 또는 창 닫기로 프로그램이 정상 종료되는지 확인한다.

## 8. 향후 확장 가능성

현재 버전은 충돌·점수·사운드 없이 공 생성, 방향 이동, 화면 밖 제거,
방향 메시지 출력까지만 제공한다. 이후 다음 기능을 확장할 수 있다.

1. 공과 캐릭터 및 지형의 충돌 처리
2. 공 발사에 따른 점수와 게임 규칙
3. 발사음과 공 이동 효과음
4. 화면 내부 방향 안내 및 발사 이펙트
