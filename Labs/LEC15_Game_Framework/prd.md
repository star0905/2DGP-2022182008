# LEC15 게임 프레임워크 - 아이템 선택 모드 PRD

## 1. 문서 개요

### 1.1 목적

현재 게임의 로고, 타이틀, 플레이, 정지 모드 흐름을 유지하면서 플레이 중
아이템 선택 모드를 추가한다. 아이템 선택 모드는 현재 화면 위에
`item_select.png`를 표시하고, 선택한 아이템에 따라 스페이스 키로 발사하는
공의 종류를 결정한다.

### 1.2 대상

- `Labs/LEC15_Game_Framework/main.py`
- `Labs/LEC15_Game_Framework/game_framework.py`
- `Labs/LEC15_Game_Framework/logo_mode.py`
- `Labs/LEC15_Game_Framework/title_mode.py`
- `Labs/LEC15_Game_Framework/playname.py`
- `Labs/LEC15_Game_Framework/pause_mode.py`
- 신규 `item_mode.py`
- `boy.py`, `ball.py`, `game_world.py`

### 1.3 제공 자산

- `item_select.png`: 아이템 선택 화면 이미지
- `ball21x21.png`: 작은 공
- `ball41x41.png`: 큰 공

## 2. 현재 구조

1. `main.py`가 `game_framework.run(logo_mode)`를 실행한다.
2. `logo_mode`는 일정 시간 후 `title_mode`로 전환한다.
3. `title_mode`에서 스페이스를 누르면 `playname`으로 전환한다.
4. `playname`에서 ESC를 누르면 `title_mode`로 돌아간다.
5. `playname`에서 P를 누르면 `pause_mode`를 스택에 올린다.
6. `pause_mode`에서 P를 누르면 `pop_mode()`로 플레이 화면에 복귀한다.
7. 모드 전환에는 `change_mode()`와 `push_mode()/pop_mode()`를 사용한다.

## 3. 기능 목표

1. 플레이 중 I 키를 누르면 아이템 선택 모드를 현재 화면 위에 표시한다.
2. 아이템 선택 모드에서 다음 숫자 키로 아이템을 선택한다.
   - `0`: 아이템 없음
   - `1`: 작은 공
   - `2`: 큰 공
3. 선택된 아이템 번호를 현재 플레이 상태에 저장한다.
4. 선택 후 아이템 모드를 닫고 플레이 화면으로 복귀한다.
5. 아이템 없음 상태에서는 스페이스를 눌러도 공을 발사하지 않는다.
6. 작은 공 선택 시 `ball21x21.png`를 발사한다.
7. 큰 공 선택 시 `ball41x41.png`를 발사한다.
8. 플레이 중 P로 정지 모드에 진입하는 기존 동작을 유지한다.
9. 아이템 선택 모드와 정지 모드에서도 ESC 동작이 예측 가능해야 한다.

## 4. 사용자 시나리오

### 시나리오 A: 아이템 없음 선택

1. 타이틀에서 스페이스를 눌러 플레이 화면에 진입한다.
2. 플레이 중 I 키를 누른다.
3. 현재 화면 위에 `item_select.png`가 표시된다.
4. 숫자 0 키를 누른다.
5. 아이템 모드가 닫히고 플레이 화면으로 돌아온다.
6. 스페이스를 눌러도 공이 생성되지 않는다.

### 시나리오 B: 작은 공 선택 및 발사

1. 플레이 중 I 키를 누른다.
2. 숫자 1 키를 누른다.
3. 플레이 화면으로 돌아온다.
4. 스페이스를 누른다.
5. `ball21x21.png`를 사용하는 작은 공이 소년의 방향으로 발사된다.

### 시나리오 C: 큰 공 선택 및 발사

1. 플레이 중 I 키를 누른다.
2. 숫자 2 키를 누른다.
3. 플레이 화면으로 돌아온다.
4. 스페이스를 누른다.
5. `ball41x41.png`를 사용하는 큰 공이 소년의 방향으로 발사된다.

### 시나리오 D: 아이템 모드에서 ESC

1. 플레이 중 I 키를 눌러 아이템 모드를 연다.
2. ESC를 누른다.
3. 아이템 선택 모드가 닫히고 플레이 화면으로 돌아온다.
4. 게임 전체는 종료되지 않는다.

### 시나리오 E: 기존 정지 모드

1. 플레이 중 P를 누른다.
2. 정지 모드가 표시되고 플레이 월드의 업데이트가 멈춘다.
3. P를 다시 누른다.
4. 플레이 모드로 돌아오고 게임이 계속 진행된다.

## 5. 상세 요구사항

### 5.1 아이템 선택 모드

- 신규 모듈 이름은 `item_mode.py`로 한다.
- `game_framework.push_mode(item_mode)`를 사용해 플레이 모드 위에 올린다.
- 기존 플레이 모드와 게임 오브젝트 상태를 유지한다.
- `init()`에서 `item_select.png`를 로드한다.
- `render()`에서 플레이 화면을 먼저 보존한 뒤 선택 이미지를 화면 위에 표시한다.
- 선택 모드의 `update()`에서는 플레이 월드의 업데이트를 수행하지 않는다.
- 숫자 `0`, `1`, `2`의 `SDL_KEYDOWN`을 처리한다.
- 숫자 선택 시 선택 결과를 플레이 모드의 상태에 기록하고
  `game_framework.pop_mode()`로 복귀한다.
- 선택 모드에서 ESC를 누르면 선택을 변경하지 않고 플레이 모드로 복귀한다.
- 창 닫기 이벤트는 `game_framework.quit()`으로 전체 실행을 종료한다.

### 5.2 선택 상태

- 플레이 모드에 현재 아이템 상태를 저장한다.
- 초기 선택값은 `0`으로 한다.
- 상태 값은 다음 의미를 가진다.
  - `0`: 발사하지 않음
  - `1`: 작은 공
  - `2`: 큰 공
- 아이템 모드가 닫혀도 선택값은 유지되어야 한다.
- 플레이 모드에서 다시 I를 누르면 현재 선택값과 무관하게 선택 화면을
  열 수 있어야 한다.

### 5.3 플레이 모드 입력

- 플레이 중 I 키를 누르면 아이템 모드를 연다.
- 아이템 모드로 전달된 I 키 이벤트가 소년에게 전달되어서는 안 된다.
- P, ESC, 방향키, 스페이스의 기존 동작을 유지한다.
- 아이템 선택 모드가 열린 동안에는 플레이 모드의 일반 입력을 처리하지 않는다.

### 5.4 공 발사

- 스페이스 입력은 현재 선택된 아이템을 확인한 뒤 처리한다.
- 선택값이 `0`이면 `Ball`을 생성하지 않는다.
- 선택값이 `1`이면 작은 공 이미지를 사용하는 공을 생성한다.
- 선택값이 `2`이면 큰 공 이미지를 사용하는 공을 생성한다.
- 공은 소년의 현재 위치와 바라보는 방향을 기준으로 생성한다.
- 공은 기존처럼 게임 월드에 등록되고 화면 밖으로 나가면 제거된다.
- 기존 방향 전환, 수면 상태, 이동 애니메이션 동작은 유지한다.

### 5.5 공 클래스 설계

- `Ball` 생성자가 이미지 파일 또는 공 종류를 받을 수 있도록 확장한다.
- 기본값은 기존 동작과 호환되는 작은 공으로 한다.
- 작은 공은 `ball21x21.png`를 사용한다.
- 큰 공은 `ball41x41.png`를 사용한다.
- 이미지 캐시는 공 종류별로 관리해 매 발사마다 이미지를 다시 로드하지 않는다.
- 공의 이동 속도와 화면 밖 제거 동작은 기존 규칙을 유지한다.

### 5.6 화면 표시

- 아이템 선택 모드는 기존 플레이 화면 위에 선택 이미지를 표시해야 한다.
- `item_select.png`의 표시 위치와 크기는 이미지의 의도된 UI 배치를
  우선 사용한다.
- 플레이 화면을 지우지 않고 배경과 캐릭터가 보이는 상태에서 선택 UI를
  그린다.
- 선택 UI가 표시되는 동안 게임 오브젝트는 움직이지 않아야 한다.

### 5.7 모드 생명주기

- `playname.pause()`와 `playname.resume()`은 기존 모드 스택 흐름을
  깨뜨리지 않아야 한다.
- 아이템 모드 종료 시 플레이 모드의 오브젝트를 삭제하거나 재생성하지 않는다.
- `playname.finish()`에서만 게임 월드를 정리한다.
- 아이템 모드의 `finish()`에서는 자신이 로드한 이미지만 정리한다.
- 아이템 모드와 정지 모드는 서로 독립적으로 동작해야 한다.

## 6. 제외 범위

이번 기능에는 다음을 포함하지 않는다.

- 아이템 개수, 소모, 재충전 시스템
- 아이템 획득 연출 및 아이템 드롭
- 공과 캐릭터 또는 지형의 충돌 처리
- 점수, 체력, 사운드, 파티클 효과
- 마우스 기반 아이템 선택
- 아이템 선택 중 실시간 플레이 월드 업데이트

## 7. 구현 계획

### 단계 1: 공 종류 지원

- `Ball`이 작은 공과 큰 공 이미지를 선택하도록 확장한다.
- 기존 호출부와의 호환성을 유지한다.
- 공 생성 및 화면 밖 제거를 검증한다.

### 단계 2: 플레이 아이템 상태 추가

- `playname`에 아이템 선택 상태를 추가한다.
- 초기값을 0으로 설정한다.
- 플레이 재진입 시 필요한 초기화 정책을 명확히 적용한다.

### 단계 3: 아이템 선택 모드 추가

- `item_mode.py`를 생성한다.
- `item_select.png`를 로드하고 화면 위에 표시한다.
- 0, 1, 2 입력을 처리한다.
- 선택 결과를 플레이 모드에 전달하고 `pop_mode()`로 복귀한다.

### 단계 4: 플레이 입력 연결

- I 키 입력 시 `push_mode(item_mode)`를 호출한다.
- 아이템 선택 상태에 따라 스페이스 발사 동작을 분기한다.
- 아이템 없음 상태에서는 발사 로직을 호출하지 않는다.

### 단계 5: 전체 모드 흐름 검증

- Logo → Title → Play 흐름을 확인한다.
- Play ↔ Pause 흐름을 확인한다.
- Play ↔ Item 흐름을 확인한다.
- Play → Title 복귀와 ESC 종료를 확인한다.

cd Labs\LEC15_Game_Framework

### 수동 테스트

1. 로고가 끝난 뒤 타이틀 화면이 유지되는지 확인한다.
2. 타이틀에서 스페이스를 눌러 플레이 화면에 진입한다.
3. I 키를 누르고 `item_select.png`가 현재 화면 위에 표시되는지 확인한다.
4. 0을 선택한 뒤 스페이스를 눌러 공이 생성되지 않는지 확인한다.
5. I와 1을 차례로 입력한 뒤 스페이스를 눌러 작은 공을 확인한다.
6. I와 2를 차례로 입력한 뒤 스페이스를 눌러 큰 공을 확인한다.
7. 아이템 선택 중 ESC를 눌러 플레이 화면으로 복귀하는지 확인한다.
8. 플레이 중 P를 눌러 정지되고, P를 다시 눌러 복귀하는지 확인한다.
9. 플레이 중 ESC로 타이틀에 복귀하는지 확인한다.
10. 타이틀에서 ESC로 프로그램이 종료되는지 확인한다.
