# 10마리 새떼 비행 애니메이션 기획서

## 1. 목표

`bird_animation.png`의 새 비행 스프라이트를 사용해 화면에 10마리의 새가
무리를 이루어 등장하고, 화면의 좌우 끝에서 방향을 바꾸며 반복 비행하도록
구현한다. 기존 플레이 화면에서 소년(`Boy`)을 그리던 역할은 새떼
(`BirdFlock`)가 대신한다.

## 2. 리소스 분석과 프레임 규칙

- 원본 이미지 크기: 918 x 506 픽셀
- 시트 배치: 5열 x 3행
- 사용 프레임: 14개
  - 1행: 5개
  - 2행: 5개
  - 3행: 4개
- 논리적 프레임 영역: 183 x 168 픽셀
- 프레임 번호는 이미지의 위쪽 왼쪽에서 오른쪽 방향으로 증가한다.
- pico2d의 클리핑 좌표는 아래쪽을 원점으로 사용하므로, 화면상의 행 번호를
  `2 - row`로 변환해 위에서 아래 순서가 유지되도록 한다.

이 규칙을 사용하면 투명 여백이나 이미지 크기 차이 때문에 새의 일부가
잘리거나 프레임 순서가 거꾸로 재생되는 문제를 피할 수 있다. 마지막 행의
남는 한 칸은 사용하지 않고 14번 프레임까지만 순환한다.

## 3. 객체 구조

### `Bird`

한 마리의 상대 배치 정보를 저장하는 데이터 객체다.

- `offset_x`, `offset_y`: 새떼 중심으로부터의 위치
- `frame`: 다른 새와 애니메이션이 겹치지 않게 하는 개별 프레임 위치

### `BirdFlock`

새 10마리를 관리하는 게임 월드 객체다.

- 스프라이트 이미지는 한 번만 로드한다.
- 새들의 상대 위치를 고정해 대형을 유지한다.
- 이동, 프레임 갱신, 좌우 반전, 렌더링을 한 곳에서 관리한다.
- `game_world`에는 새 10개를 각각 등록하지 않고 새떼 객체 하나만 등록한다.
  따라서 월드 업데이트와 렌더 순서가 단순하고, 새떼를 제거하거나 교체하기
  쉽다.

## 4. 비행 이동 로직

새떼의 기준점 `(x, y)`를 만들고, 기준점의 x좌표만 시간에 따라 이동한다.
각 새는 기준점에 상대 좌표를 더해 그려지므로 새들 사이의 대형이 유지된다.

```text
x = x + direction * speed * frame_time
```

- `speed`: 초당 180픽셀
- `direction`: 오른쪽 `1`, 왼쪽 `-1`
- `frame_time`: 실제 이전 프레임과 현재 프레임 사이의 시간

프레임 시간에 속도를 곱하는 방식은 컴퓨터 성능이나 순간적인 프레임
간격에 따라 이동 속도가 달라지는 문제를 줄인다. 새떼 전체의 좌우 경계를
계산하고, 경계에 닿으면 기준점을 안전한 위치로 보정한 뒤 `direction`을
반전한다. 이 방식으로 새가 화면 밖으로 사라진 후 되돌아오는 것이 아니라
화면 안에서 자연스럽게 방향을 바꾼다.

## 5. 정확한 날갯짓 애니메이션

각 새는 14개 프레임을 다음 규칙으로 순환한다.

```text
frame = (frame + animation_fps * frame_time) % 14
```

- 애니메이션 속도: 초당 12프레임
- 그릴 때만 `int(frame)`을 사용해 정수 프레임을 선택한다.
- `frame`은 실수로 유지해 프레임 시간에 따른 누적 오차를 줄인다.

각 새의 시작 프레임을 `index * 1.4`만큼 다르게 설정한다. 모든 새가
동일한 프레임을 동시에 재생하면 기계적으로 보이므로, 위상 차이를 두어
날개 움직임이 분산되도록 했다. 이동 속도와 애니메이션 속도는 분리되어
있기 때문에 새떼의 이동 방향이 바뀌어도 날갯짓은 끊기지 않는다.

## 6. 좌우 방향 표현

원본 프레임은 오른쪽을 향한 새이므로, 새떼가 오른쪽으로 이동할 때는
원본을 그대로 그린다. 왼쪽으로 이동할 때는 `h` 수평 반전을 적용한다.
프레임 이미지를 별도로 복사하거나 뒤집은 이미지를 추가로 만들지 않으므로
메모리 사용량과 리소스 관리 비용을 늘리지 않는다.

## 7. 화면 및 게임 루프 연결

`play_mode.init()`에서 `BirdFlock`을 생성해 일반 오브젝트 레이어에 등록한다.
기존 `Boy` 생성 및 이벤트 전달은 제거하고, ESC와 종료 이벤트만 모드가
처리한다. 이후 게임 루프는 기존과 동일하게 동작한다.

1. `game_world.update()`가 새떼의 위치와 10개 프레임 상태를 갱신한다.
2. `game_world.render()`가 새떼를 그린다.
3. 배경 잔디와 눈금자는 기존 배경 레이어에서 계속 렌더링한다.

이 구조는 새떼를 게임 월드의 일반 객체 규칙에 맞춰 통합하면서도 기존
게임 프레임워크의 업데이트·렌더 순서를 변경하지 않는다.

## 8. 검증 기준

- 화면에 정확히 10마리가 보인다.
- 새의 날개 프레임이 14개 범위에서 순환한다.
- 새떼가 오른쪽과 왼쪽으로 반복 이동한다.
- 방향 전환 시 새 이미지도 수평 반전된다.
- 새떼의 대형이 이동 중 유지된다.
- `game_world`가 새떼를 한 객체로 업데이트하고 렌더링한다.
